## PaizaParser（テストケースを自分で考えてから実装する）
- [x] technologies の重複除去（完全に同じ文字列）→ `Array#|` で除去。主要開発技術と開発言語に同じ技術がある小さなHTMLでテスト済み（実装をわざと壊すと赤くなることも確認）

- [ ] 給料の「〜」の別の文字（全角チルダ `～` U+FF5E、半角 `~`）が使われていたときの扱い。今は波ダッシュ `〜` U+301C だけを確かめている
- [ ] 取り出した文字列を Unicode の NFC にそろえるか（`unicode_normalize(:nfc)`）。macOS 由来などの NFD（例: 「プ」が「フ＋゜」の2文字）が混ざると、同じ技術名が別物として数えられる
- [ ] 求人ではないページ（ロボット対策ページなど）を渡したとき
